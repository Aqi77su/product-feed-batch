# 验收与明确边界

## 自动检查

- 源哈希、实际素材时长/音轨、文案分组与数量正确。
- 源绝对毫秒只映射一次：1.1倍速、多人接续、批次偏移一致；词时间不伪造。
- 同一口播区间无重复主体；[start,end)样式完整覆盖全部受支持字符；字体内外引用完整。
- 模板完整依赖和子文字存在，替换后无历史文案；不把模板ID当字效ID。
- 语义实拍有真实锚点、匹配标签；不跨源段/成片/用户禁区，实拍静音，源裁切合法。
- 音乐每条作用域、源起点、淡出正确；音效不越界，候选池缺资源有明确失败/降级。
- 标题、矩形、竖排、底部必要文字分角色；不清除声明标点，不缩小到不可读字号。
- 源素材和本地字体/效果依赖打包，segments-index.csv与计划一致。
- 失败保留INCOMPLETE，不覆盖旧草稿。随机计划可复现，UUID不承诺字节一致。

运行 `python -m unittest discover -s tests -p "test_*.py" -v`。端到端测试使用临时合成视频、音乐、图片与模板结构，不使用私人资料，不执行云端识别。

## 首次目标剪映检查

资源第一次进入白名单之前，先在目标剪映的原生界面手工选择该字体/动画/花字/模板，替换成短句、长句和数字检查显示；可使用用户已有且在该目标版本正常播放的人工工程作为来源。记录实际检查版本后再启用catalog.verified。提取工具和结构测试不会自动授予视觉验证。若尚无任何已验证资源，不能通过提前写true来生成所谓首次小样，也不能谎称程序能验证自身像素。

已完成资源自身验证后，生成2条编排小样：普通/长句/数字、原位关键词、完整模板、开场卡、标题底板/竖排/必要说明、多段接续和实拍。确认草稿实际出现、字体与动画显示、单行边界、信息不遮挡、音画和字幕同步、音乐听感/尾淡出、资源可迁移。完成整套编排检查后才扩大生产数量。

静态检查与字体测宽估算不能证明剪映最终像素、外发光或动画中间态；本版不承诺所有11.x加密根元信息注册。没有本机剪映时如实报告“离线生成/结构通过，剪映打开未验证”，不能假通过。

## 不自动处理的情况

- 缺失本机软件：先说明并询问安装；不下载未知DLL、不修改系统PATH、不升级降级剪映。
- 失去可靠词时间：auto模式记录跳过词级动画；word模式报错，plain策略才可降级。不自动精准听音重对齐。
- 长句无词时间：默认报错要求按真实口播重断句；明确选择approximate_equal才允许句级等时拆分，并标近似。
- 不同文案多槽模板、非BMP特殊字符：明确拒绝，不丢弃内容假装支持。
- 缺所需效果：默认error；plain必须显式选择，报告缺失效果。原位border模式本身是合法可选风格，不冒充花字。
- 未知编号素材：不能编造视觉标签；没有匹配窗口则保留人物并报告，不为比例乱填。
- 状态端口只绑定127.0.0.1，完成后短暂查询窗口自动关闭，不是后台定时器。
