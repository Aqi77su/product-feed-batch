# 第一版验收与限制

开发验证只在工作区隔离目录进行。首次在真实剪映使用，生成两条小样检查：

1. 草稿列表是否显示，若不显示先查版本/注册结构，不自动覆盖根元信息。
2. 数字人原声、时长、口型保持同步，主轴顺序正确。
3. 实拍在数字人上方、字幕下方，禁插区无实拍；不同画幅的裁切符合预期。
4. 基础字幕字体/描边/位置生效；关键词高亮和花字没有遮挡必要信息。
5. 持续透明图、广审文字未变形、未缺字；各成片单元结束时一并结束。
6. 音乐/音效不跨相邻成片边界；基底原声没有被静音。
7. materials 文件可读，字体/效果依赖完整；segments-index.csv 与时间线一致。

脚本 verify 检查结构及文件引用，不证明视觉效果、字体或资源在剪映中可用。第一版明文 draft_info.json 和元信息由上游生成器产生，未适配所有 11.x 加密根注册方式；本机未安装剪映时只能完成离线结构验证。

大量工作失败可重新规划并生成新草稿；成功识别结果不重复上传。除非用户授权，不安装缺失软件、不清理原素材或工程、不改变系统 PATH、不升级/降级剪映。

关键词采用句内高亮 + 独立强调轨，第一版不为每个字生成卡拉 OK 时间轴。基础字幕最大长度/多行适配由 AI 校正断句和布局参数控制；未实现自动“精准听音重对齐”。任何在校正中失去词级依据的关键词使用句级时间。

状态服务是只读运行窗口，任务结束自动关闭；不是后台调度器，不支持远程访问。单个批次一条总时间线，人工按索引范围导出，不代表每条已经建立独立导出区间。
