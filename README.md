# 产品信息流批量剪辑 Skill

把已有的有声数字人口播与同产品实拍，随机批量编排为 **可编辑的剪映草稿**。一个工程的主时间线上依次排列全部成片，用户审核后按索引逐条导出。

AI 负责收集需求、分析参考成品布局、解析多篇文案、校正字幕和标记关键词；程序负责数量分配、随机实拍裁切与插入、字幕/花字/动画/音效/音乐配置和草稿生成，不为每条变体调用 AI 做剪辑决策。

## 安装与使用

将本仓库复制或克隆到支持 Skill 的 AI 工具的技能目录。例如 Codex：

```powershell
git clone https://github.com/Aqi77su/product-feed-batch.git "$env:USERPROFILE\.codex\skills\product-feed-batch"
```

新建对话并说：

> 加载 $product-feed-batch，先检查环境，我要批量制作产品信息流视频。

首次加载自动检查环境，缺少剪映、Python、Node 或运行依赖时先询问是否安装。日常提供数字人口播目录、实拍目录、生产数量、可选多篇文案、参考成品和持续图文贴片。Skill 会先核对真实文件与数量分配，再让用户确认。

完整流程：[SKILL.md](SKILL.md)。任务参数：[任务格式](references/job-format.md)。效果白名单：[资源说明](references/resources.md)。首次真实使用：[验收](references/acceptance.md)。

## 环境

- 第一版目标：Windows、Python 3.10+、Node 18+、安装并启动过的剪映专业版。
- FFmpeg 优先使用现有安装，也可使用私有 Python runtime 的 imageio-ffmpeg。
- 工程与字幕工具固定源码已经在 vendor/ 内置；无需外部 Skill、运行时 git clone 或 npm install。
- Python 基础依赖安装在私有 runtime 中，必须先得到用户同意。
- 字幕识别会提取并上传音频到字节云端。它使用非官方公开 SDK 的客户端接口实现，服务可用性可能变化。已有字幕可以导入并复用。

## 能力和当前边界

- 批量数量均匀或指定分配；同一口播字幕识别一次，多版本共享。
- 主视频原声和速度保持；实拍静音，避开头尾禁插区。
- 持续标题、透明产品信息图、说明文字独立可编辑。
- 随机种子可复现；每条基础字体一致，音乐和效果从配置集合选择。
- 只读本地状态端口，以及成片编号/时间范围 CSV。
- 不覆盖同名草稿；失败保留 INCOMPLETE 标记。

已完成离线多源、多版本草稿生成及结构检查，验证过材料引用、时间边界、随机规划和状态接口。**尚未在本机剪映中打开验证**；新版本草稿列表注册、字体/效果显示和大批次性能需先做小样验证。默认效果白名单为空，未经对应版本验证的缓存不会自动随机使用。

不包含数字人生成、HTML 界面、MP4 自动导出、加密参考工程解密或相邻实拍叠化转场。参考成品通过抽帧分析布局，不宣称由少量截图完整理解连续运动。

## v0.2

支持按完整文案自动提出单人/多段拼接/不确定模式，用户确认段落候选后无放回抽组合；混合批次可按多个脚本组配置。字幕金色字号13、y=-0.39，字体优先得意黑/俪金黑；音乐0.36从头播放、不循环、不淡入淡出；每条默认1段5–15秒实拍。详见 [成片分组与默认风格](references/assembly.md)。资源候选按用户提供清单收录，实际字体、音乐缓存路径与花字类型仍需在本机定位验证。
